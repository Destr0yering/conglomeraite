# MVP evidence

This directory contains sanitized, commit-safe observations generated by real runs. API keys, prompts that may contain private data, full model drafts, and local runtime secrets do not belong here.

- `live-cloud-smoke-v3.summary.json` records the first live QwenCloud 8/10 to 10/10 convergence run after rubric propagation and truncation handling were fixed.
- `baseline-vs-swarm-pilot.json` is generated by the benchmark harness and uses task hashes rather than task or output text.
- `edge-sysop-smoke.summary.json` records one real advisory inference through the Nano's existing SYSOP Qwen Bridge plus a post-call unified-memory snapshot.
- `nano-outage-demo.summary.json` records the controlled zero-paid cloud-loss run on the deployed Nano: two degraded calls routed to the SYSOP bridge, the best 8/10 candidate was retained, the bounded deadline stopped the loop, and the constrained model service remained healthy with zero restarts.
- `alibaba-function-compute.summary.json` records the live Function Compute health, unsigned rejection, and signed metadata acceptance checks without a reusable secret.
- `demo-video.summary.json` describes the locally assembled 2:55 Andrew neural-voice evidence video; its source script, voice renderer, and narration are committed for reproducibility.

The first two records are development-laptop observations; the outage record is target-device evidence. External or blinded quality evaluation remains a separate submission requirement.
